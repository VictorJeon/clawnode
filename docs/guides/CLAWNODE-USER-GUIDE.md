## 1. ClawNode가 뭔가요?

ClawNode는 **당신만의 24시간 AI 직원**입니다.

설치하고 나면 텔레그램에서 메시지 한 줄로 AI에게 일을 시킬 수 있어요.

```
나: "오늘 업계 뉴스 요약해줘"
AI: (30초 후) 오늘 주요 뉴스 10개 정리해드렸습니다...

나: "저번에 말한 거래처 연락처 찾아줘"
AI: 지난달 17일에 말씀하셨던 OO 대표님 연락처입니다...
```

핵심은 두 가지예요.

**① 기억합니다.** 3개월 전에 지나가듯 한 말도 기억해요. 세션이 끊겨도, 맥미니를 재시작해도 사라지지 않아요.

**② 실제로 일합니다.** 검색, 파일 작성, 이메일 발송, 스케줄 관리, 자동화까지. 답변만 주는 게 아니라 직접 처리해요.

---

### 구조를 한 줄로

```
텔레그램(내 폰) ←→ 맥미니(AI 서버) ←→ Claude/GPT API
```

맥미니가 집에서 조용히 돌아가면서 텔레그램 메시지를 받고, AI로 처리하고, 결과를 돌려줘요. **24시간 꺼지지 않아요.**

## 2. 기존 AI와 뭐가 다른가요?

| | ChatGPT / Claude 웹 | Claude Code | **ClawNode** |
|--|--|--|--|
| 접근 방법 | 브라우저 | 터미널 | **텔레그램** |
| 장기 기억 | ❌ 세션 종료 시 리셋 | ❌ 프로젝트별 | **✅ 영구 기억** |
| 자동화 | ❌ 직접 실행 필요 | 제한적 | **✅ cron 스케줄** |
| 내 파일 접근 | ❌ | ✅ | **✅** |
| 24시간 운영 | ❌ | ❌ | **✅** |
| 보안 | 클라우드 전송 | 로컬 | **로컬 + 암호화** |
| 커스텀 | 제한적 | 제한적 | **완전 커스텀** |

### V3 장기기억 시스템

ClawNode의 핵심 차별점이에요.

일반 AI는 대화가 끝나면 모든 걸 잊어요. 클로드코드도 프로젝트 파일이 없으면 기억 못 해요.

ClawNode는 **pgvector 기반 벡터 데이터베이스**를 맥미니에 직접 구축해요.

- 대화 내용 자동 추출 → 핵심 사실만 압축 → DB에 저장
- 새 대화 시작 시 관련 기억 자동 검색 → 맥락 유지
- "저번에 말한 그거"가 3개월 뒤에도 통해요

```
[대화] → [자동 추출] → [벡터화] → [DB 저장]
                                        ↓
[새 대화] ← [관련 기억 검색] ← [의미론적 검색]
```

## 3. 내 컴퓨터에서 맥미니 접속하기

설치 후 맥미니는 집/사무실에 조용히 켜져 있어요.  
텔레그램으로 쓰는 게 기본이지만, 직접 접속해서 개발하고 싶을 때는 아래 방법을 쓰세요.

---

### 3-1. Tailscale 설정 (원격 접속의 핵심)

Tailscale은 보안 VPN이에요. 어디서든 맥미니에 접속할 수 있게 해줘요.

**내 컴퓨터(Mac/Windows)에 Tailscale 설치:**

1. [tailscale.com/download](https://tailscale.com/download) 접속
2. 운영체제에 맞는 버전 다운로드 및 설치
3. 앱 실행 → **같은 계정으로 로그인** (설치 시 사용한 계정)
4. 설치 완료 후 Tailscale 메뉴에서 맥미니가 보이면 성공

**맥미니 IP 확인:**

```bash
# 맥미니 터미널에서
tailscale ip
# 결과 예시: 100.x.x.x
```

---

### 3-2. SSH로 터미널 접속

터미널(Mac: Terminal.app, Windows: PowerShell)에서:

```bash
ssh 사용자명@100.x.x.x
# 예시: ssh wade@100.81.242.59
```

처음 접속 시 "Are you sure you want to continue connecting?" → `yes` 입력

**SSH 공개키 등록 (비밀번호 없이 접속):**

```bash
# 내 컴퓨터에서 실행
ssh-keygen -t ed25519 -C "my-key"
# 기본 경로 그대로 Enter → 비밀번호 설정 or Enter

# 공개키를 맥미니에 복사
ssh-copy-id 사용자명@100.x.x.x
# 또는 수동으로:
cat ~/.ssh/id_ed25519.pub | ssh 사용자명@100.x.x.x "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

이후 `ssh 사용자명@100.x.x.x` 만 치면 비밀번호 없이 접속돼요.

---

### 3-3. VS Code로 파일 편집

VS Code에서 맥미니 파일을 직접 열고 편집할 수 있어요.

1. VS Code 설치: [code.visualstudio.com](https://code.visualstudio.com)
2. 확장 설치: `Remote - SSH` (검색창에서 설치)
3. 좌측 사이드바 → 리모트 아이콘 → `+` 버튼
4. `ssh 사용자명@100.x.x.x` 입력 → Enter
5. 맥미니 폴더를 VS Code에서 직접 열기

이제 맥미니의 파일을 내 컴퓨터에서 편집할 수 있어요.

---

### 3-4. 파일 전송 (SCP)

```bash
# 내 컴퓨터 → 맥미니
scp 파일명 사용자명@100.x.x.x:~/폴더/

# 맥미니 → 내 컴퓨터
scp 사용자명@100.x.x.x:~/파일명 ./
```

## 4. 주요 명령어 정리

### OpenClaw CLI

```bash
# 상태 확인
openclaw status

# 재시작
openclaw gateway restart

# 로그 확인
openclaw logs

# 설정 확인
openclaw config get

# 스킬 목록
openclaw skills list

# cron 잡 목록
openclaw cron list

# 헬스체크
openclaw doctor
```

### Memory V3

```bash
# 메모리 검색 (직접)
curl -s -X POST http://127.0.0.1:18790/v1/memory/search \
  -H 'Content-Type: application/json' \
  -d '{"query": "검색어"}'

# 메모리 통계
curl -s http://127.0.0.1:18790/v1/stats

# atomize 대기열 확인
psql -d memory_v2 -c "SELECT count(*) FROM pending_atomize;"
```

### 서비스 관리

```bash
# OpenClaw 서비스 상태
launchctl list | grep openclaw

# PostgreSQL 상태
brew services info postgresql@17

# 전체 재시작
launchctl kickstart -k gui/$(id -u)/com.openclaw.gateway
```

## 5. 기본 사용법

### 텔레그램에서 쓰기

그냥 말 걸면 돼요. 특별한 명령어 없어요.

```
✅ "오늘 할 일 뭐가 있더라?"
✅ "어제 말한 미팅 자료 정리해줘"
✅ "삼성전자 오늘 주가 확인해줘"
✅ "이 PDF 요약해줘" (파일 첨부)
✅ "매일 아침 8시에 날씨 알려줘"
```

### SOUL.md — AI 성격 설정

맥미니의 `~/.openclaw/workspace/SOUL.md` 파일이 AI의 성격을 정해요.

```bash
# VS Code로 편집
code ~/.openclaw/workspace/SOUL.md
```

예시:
```markdown
# SOUL.md

- 항상 한국어로 답변
- 결론 먼저, 설명은 나중에
- 비즈니스 맥락에서 판단할 것
- 매일 아침 9시에 할 일 브리핑
```

수정하면 다음 대화부터 바로 반영돼요.

### AGENTS.md — 업무 지침

AI가 어떻게 일할지 구체적인 지침을 써요.

```bash
code ~/.openclaw/workspace/AGENTS.md
```

예시:
```markdown
# AGENTS.md

## 보고 방식
- 결과만 간결하게
- 불확실하면 솔직히 말할 것

## 우선순위
1. 데이터 안전
2. 정확성
3. 속도
```

### HEARTBEAT.md — 자동 모니터링

AI가 주기적으로 확인할 것들을 적어요.

```bash
code ~/.openclaw/workspace/HEARTBEAT.md
```

예시:
```markdown
# HEARTBEAT.md

- 서버 CPU 90% 이상이면 알림
- 미확인 텔레그램 메시지 2시간 이상이면 리마인드
- 매주 월요일 주간 업무 정리 보고
```

## 7. 보안 & 개인정보

### 데이터는 맥미니에만 있어요

- 모든 대화 내용, 메모리, 파일은 **맥미니에만 저장**돼요
- 클라우드 서버로 전송되지 않아요
- AI API(Claude/GPT)에는 처리할 내용만 전송, 저장 없음

### 외부 접근 차단

- OpenClaw Gateway는 **127.0.0.1(내부)에만 바인딩**
- 외부 IP에서 직접 접근 불가능
- Tailscale은 암호화된 P2P 연결 (WireGuard 프로토콜)

### API 키 관리

- 모든 API 키는 **macOS Keychain**에 암호화 저장
- 코드나 파일에 평문으로 저장하지 않아요

### 원격 접속 제어

- Tailscale에서 언제든 기기 제거 가능
- SSH 공개키 삭제로 원격 접속 즉시 차단

## 8. FAQ

**Q: 맥미니를 꺼도 되나요?**  
A: 꺼지면 AI가 응답하지 않아요. 24시간 운영하려면 켜두셔야 해요. 전력 소비는 월 1,000~2,000원 수준이에요.

**Q: 인터넷이 끊기면 어떻게 되나요?**  
A: 인터넷 연결이 복구되면 자동으로 재연결돼요. 그동안은 응답 없어요.

**Q: AI 모델을 바꿀 수 있나요?**  
A: 네. Claude, GPT, Gemini 등 원하는 모델로 언제든 변경 가능해요. 모델별로 API 요금이 달라요.

**Q: AI API 요금은 얼마나 나오나요?**  
A: 사용량에 따라 다르지만 일반적인 개인 사용 기준 월 1~5달러 수준이에요. 많이 써도 20달러 이상은 드문 편이에요.

**Q: 여러 명이 같이 쓸 수 있나요?**  
A: 텔레그램 계정 여러 개를 연결하면 팀이 함께 쓸 수 있어요. 단, 메모리는 공유돼요.

**Q: 스킬은 뭔가요?**  
A: AI에게 특정 작업 방법을 가르치는 파일이에요. "이런 상황에서는 이렇게 해"라는 지침서. 새로운 작업이 필요하면 스킬을 추가하면 돼요.

**Q: 데이터를 백업할 수 있나요?**  
A: `~/.openclaw/` 폴더 전체를 백업하면 돼요. 메모리, 설정, 스킬 모두 포함돼요.

**Q: 맥미니가 고장나면 어떻게 되나요?**  
A: 백업이 있으면 새 기기에 재설치 후 복원 가능해요. 저희가 도와드려요.

**Q: OpenClaw 업데이트는 어떻게 하나요?**  
A: 텔레그램에서 "업데이트해줘"라고 하면 알아서 해요. 또는 `openclaw update` 명령어.

**Q: 추가 기능은 어떻게 요청하나요?**  
A: claw-node.com 카카오톡 채널로 문의 주세요. 유지보수 계약 고객은 우선 지원이에요.

## 9. 문제 해결

### AI가 응답하지 않을 때

```bash
# 1. 상태 확인
openclaw status

# 2. 재시작
openclaw gateway restart

# 3. 로그 확인
openclaw logs | tail -50
```

### 기억이 안 될 때

```bash
# 메모리 서비스 상태 확인
launchctl list | grep memory

# atomize 대기열 확인 (숫자가 크면 처리 중)
psql -d memory_v2 -c "SELECT count(*) FROM pending_atomize;"
```

### 텔레그램 연결이 끊겼을 때

```bash
openclaw gateway restart
```

대부분 재시작으로 해결돼요.

### SSH 접속이 안 될 때

1. 맥미니가 켜져 있는지 확인
2. Tailscale이 두 기기 모두 실행 중인지 확인
3. 같은 Tailscale 계정인지 확인

```bash
# Tailscale 상태 확인
tailscale status
```
